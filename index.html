Project 02 · Problem
02 · Cross-border partner platform

C2C chat is not a B2B workspace. Ops ran on Excel.

Bunjang · Product Manager · 2026.01 – Present · rapid YoY channel growth
The channel
Rapid YoY growth on chat accounts + Excel

Proxy-purchase volume outgrew its tooling. No squad, no mandate, and no owner for the workflow.

The evidence
10+ partner interviews · 2025.12 workflow audit

Every partner described the same loop: find the order in a chat thread, re-key it into a workbook, reconcile by hand.

Why it mattered

Each re-entry is an unlogged decision. With nothing to search, assign, or settle against, ops capacity — not demand — capped the channel.

10
Project 02 · Decision

Patch the chat, script the spreadsheets, or build the platform.

Option A REJECTED · SYMPTOM FIX
Improve the chat tool

Faster triage inside chat. Search, settlement, and API control stay manual.

Option B REJECTED · NO SCALE
Automate the spreadsheets

Scripts over the workbooks. Fast to ship, collapses again at partner scale.

Option C SELECTED
Dedicated partner platform

Order-centric workspace: search, alerts, settlement, API keys, role-based approvals. Needed a squad that did not exist.

The artifact
16.5K LOC · LINE-BY-LINE WALKABLE

A walkable prototype of the whole workflow replaced a spec no one would read.

The alignment
12-PERSON DELIVERY SQUAD

No authority was granted. The artifact was what a squad agreed to build.

Takeaway · Authority was never granted. A working artifact aligned a 12-person delivery squad.

One shared core. Local exceptions became plugins, not forks.

Option B Force one global standard One codebase, no exceptions. Tax, certification, and invoice rules genuinely diverge by country. REJECTED · RULES DIVERGE
Option C Shared core + country plugins Certification, tax refund, and bulk flows as country extensions under global guardrails. SELECTED

Selected deployment · 05 · Invoice automation · LG Electronics · 2025.06 – 2025.08

Manual invoice requests, 33 per month, went to zero.

Problem

Business invoices ran on manual ERP requests: 33 tickets, roughly 21 MD, every month. Each market's tax rules lived in people's heads, not the system.

Approach

Documented mandatory market fields once, then split the schema into a shared core plus country-specific extensions. A new market became a mapping, not a project.

Load it absorbed

The same workflows carried a 221% increase in invoice volume across 12 countries, with no added headcount and no return to the twice-daily manual overload.

Case 1 - LG D2X: Connecting Disconnected Data Across 30 Countries

LG Electronics | 2023 - 2025 | Recognized at LG Group-wide Innovation Award (2nd Place)

Problem

Twelve LG Home Appliances country subsidiaries each ran their own invoicing pipeline against a central Master Table. Pilot markets were producing out-of-memory errors twice a day. The errors looked like a code issue, but no patch held. Manual recovery cost roughly 165 hours per market per month.

Approach

Treated this as a structural problem, not a code bug. Went onsite with each subsidiary, mapped the actual workflow against the system, and uncovered that the Master Table was being full-scanned at every send. Designed a sender-only intermediate table with a clean mapping contract, then piloted in Taiwan before global rollout.

Reflection

Data problems usually live in structure, not in the code. A single new table - the right one, with the right contract - stabilized an entire 12-country pipeline. The harder work was alignment: ERP, MW, OMS, and tax teams across four subsidiaries had to agree on the contract before a single line of code shipped.

Case 2 - Bunjang Partner Platform: From Field Interviews to a Working Cross-border Prototype

Bunjang | 2026 - Present | Phase 1 launch in progress, 5-engineer squad

Problem

Bunjang's C2C marketplace had no system for international partners (Mercari, Rakuten, Doorzo) to sell into Korea. Orders, status updates, escrow, and disputes were all happening in spreadsheets and chat threads. Operations could not scale past a handful of partners.

Approach

Conducted 10+ field interviews directly with international partners. Mapped the actual operating workflow - the 15 steps a partner takes from listing to settlement, the 14 states an order can be in, the 6 approval gates that human moderators apply. Built a working React TypeScript prototype (16.5K lines) using AI-assisted coding workflows to validate the model live with partners.

Outcome

The prototype became the spec. Engineering used it as a living reference instead of static docs, and partners signed off on the operating model before code shipped. Phase 1 launch is in progress with a dedicated 5-engineer squad.

Reflection

Building the demo before the spec changed what was possible to align on. Partners corrected things in the prototype that they would not have written down in a doc. AI-assisted coding made it economical for a single PM to do this end-to-end.
